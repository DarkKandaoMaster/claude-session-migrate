# 换号后找回 Claude 桌面应用会话：用户须知

这份文档写给使用者本人看。技能本身的说明见 `claude-session-migrate/SKILL.md`。

## 一句话原理

切换账号后，会话并没有被删除。对话内容存放在 `~/.claude/projects`，这里的文件和账号无关；侧栏的会话列表则按“账号\组织”分文件夹存放。换号后，桌面应用就去读新账号的文件夹，旧会话因此不再显示。恢复的办法是把旧文件夹里的会话索引复制到新文件夹。

## 动手前

1. **不要在桌面应用的 Code 标签页里让 Claude 执行迁移。** 迁移过程中必须退出桌面应用，你和 Claude 的这次对话也会跟着中断。请改用命令行（`claude`）或 VS Code 扩展打开会话后再操作。
2. **用新账号至少打开过一次桌面应用**，否则新账号的文件夹还不存在。
3. **先预览，确认无误后再执行。** 预览不会改动任何文件。在预览结果里核对两点：
   - `[目标]` 是刚登录的新账号，通常是最后修改时间最新的那一个；
   - `[源]` 是旧账号，通常是会话数最多的那一个。

## 执行时

4. **彻底退出桌面应用。** 只关窗口不够，要在托盘图标上右键选择退出。
   - 退出后不要误点重新打开。应用运行时会把内存里的会话列表写回磁盘，覆盖刚复制过去的文件。
   - 脚本发现应用还在运行时会拒绝执行，并列出进程号。不要用 `-Force` 跳过这项检查。
   - VS Code 扩展和命令行里的 `claude.exe` 不算桌面应用，不需要关闭。
5. **商店版（Microsoft Store 安装）的数据不在 `%APPDATA%\Claude`。** 真实位置在 `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude`。脚本会自动找到这个位置；如果你要手动操作，记得去这里找。
6. 脚本会先把整个 `claude-code-sessions` 文件夹备份到 `~\claude-session-backups\`，然后再复制。**请记下备份路径，回滚时要用。**

## 完成后

7. **打开桌面应用检查**：侧栏应该出现旧会话，点开能看到对话内容。
8. **部分会话可能“有标题没内容”。** 这些会话的对话内容已经被 Claude 按 `cleanupPeriodDays` 设置自动清理（默认保留 30 天），找不回来了。脚本执行完会列出这些会话的标题，可以在侧栏里把它们删掉。
9. **旧账号的权限设置会一起带过来。** 例如权限模式、“始终允许”过的操作、computer-use 授权过的应用等。如果介意，打开这些旧会话时留意一下。
10. **侧栏的自定义分组和收藏恢复不了。** 换号时它们就已经被清空，这次复制无法找回。

## 出问题怎么办

- **复制后侧栏仍然不显示**：新版应用可能改成以服务器上的数据为准了。先彻底退出应用，再用 `-Restore <备份路径>` 还原。脚本会把当前文件夹改名保留，不会删除。
- **兜底方法**：只要对话内容还在，就可以进入对应的项目目录，运行 `claude --resume` 选择会话继续，这种方式不依赖侧栏。
- 不再需要的备份或改名后的旧文件夹，先移到 `_待删除/`，确认无误后再手动删除。
